What is a blockchain?

A blockchain is a shared record of transactions, grouped into blocks and chained together so that changing an old entry would mean redoing everything after it.

How it works

  1. You send a transaction. It goes into a waiting area called the mempool.
  2. A validator (a miner or staker, depending on the network) picks transactions and packs them into a block.
  3. The block is broadcast and every node checks it against the network's rules.
  4. Each new block built on top of yours is one more confirmation. More confirmations means the transaction is harder to undo. Most platforms wait for a set number of confirmations before crediting funds.

Why it matters to you

  • Transfers are final. Once confirmed, an on-chain transaction cannot be cancelled, reversed or recalled — not by you, not by Betabase, not by anyone. Sending to a wrong address usually means the funds are gone.
  • Networks are separate. The same-looking address on two different networks is not interchangeable. Sending an asset over the wrong network can cause permanent loss.
  • Fees vary. Network fees are set by network demand, not by Betabase. They rise when the network is busy.
  • Speed varies. Confirmation times range from seconds to over an hour depending on the network and congestion.

Always check the address and the network twice before you confirm any on-chain withdrawal. There is no undo.
