How to deposit cryptocurrency into your Betabase account

Deposit crypto by generating a deposit address for that specific asset and network inside Betabase, then sending to it from your external wallet or exchange.

Before you start

  • Verification complete.
  • Confirm that Betabase supports both the asset and the network you intend to send on.
  • Check the deposit minimum for that asset.

Steps

  1. Select Deposit → Crypto.
  2. Search for and select the asset you are sending — for example the exact token, not a similarly named one.
  3. Select the network (chain). This must match the network your sending wallet will actually use.
  4. Betabase shows a deposit address, and for some assets a memo or destination tag.
  5. Copy the address using the Copy button — never retype it by hand. Copy the memo/tag too if one is shown.
  6. In your external wallet, paste the address and the memo/tag, select the same network, and enter the amount.
  7. Send a small test amount first if this is a new address or a large transfer.
  8. Send, then return to Betabase. The deposit shows as Pending until it has enough confirmations.

Good to know

  • Deposit addresses are unique to you and to that asset/network pair. Reusing an old address is generally fine unless the app says otherwise, but always re-copy it to be safe.
  • Some wallets show the address as a QR code — scanning it is safer than pasting.
  • Network fees are charged by the blockchain and deducted by the sending wallet, not by Betabase.

Send only the named asset, on the named network, to that address. Sending anything else — or omitting a required memo — can mean permanent loss. Blockchain transactions are irreversible: once confirmed, nobody, including Betabase, can cancel, reverse or recall them.
