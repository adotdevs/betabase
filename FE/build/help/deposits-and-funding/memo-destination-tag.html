What is a memo / destination tag and when do I need one?

A memo (or destination tag) is a short code that tells Betabase which customer a deposit belongs to, because some networks route every user's funds through one shared address.

Which assets need one

Networks that use a shared deposit address require a memo or tag. These commonly include XRP (destination tag), XLM (memo), EOS, ATOM, HBAR, ALGO and some others. The deposit screen tells you plainly: if a memo field is shown, it is mandatory.

Steps

  1. Open Deposit → Crypto and select the asset and network.
  2. If a memo/tag is required, Betabase shows it below the address, clearly labelled.
  3. Copy the address into the address field of your sending wallet.
  4. Copy the memo/tag into the wallet's memo, tag, note or reference field. It is a separate field — never paste it into the address.
  5. Check both against the original before you send.
  6. Send.

Good to know

  • The memo is not optional and it is not a personal note. It is the only thing that identifies you inside a shared address.
  • Some wallets label the field differently: Memo, Tag, Destination tag, Note, Comment. If in doubt, look for the field that appears only for that specific coin.
  • If your wallet has no memo field, it probably cannot send that asset correctly. Use a wallet that does.

A deposit sent without a required memo, or with the wrong memo, does not credit automatically. Recovery is sometimes possible but is manual, slow, may carry a fee, and is not guaranteed. Contact support@www.betabase.pro with the transaction hash, the amount and the date. Blockchain transactions are irreversible — we cannot reverse the transfer, only attempt to identify it.
