I didn't receive the SMS verification code

If your SMS code hasn't arrived within two minutes, it is almost always a carrier delay, a wrong number on file, or a blocked short code — not a problem with your account.

Before you start

  • Confirm the phone number shown on the code screen is the number you actually hold.
  • Make sure you have mobile signal. SMS does not deliver over Wi-Fi only.

Steps

  1. Wait a full 60–120 seconds. Carrier delivery is not instant, especially when roaming.
  2. Toggle flight mode on and off to force your handset to re-register with the network.
  3. Check your phone's blocked numbers, spam folder and any SMS-filtering app. Short codes are often silently filtered.
  4. On the code screen, select Resend code. Wait for the countdown to finish — requesting repeatedly can trigger a temporary rate limit.
  5. If it still fails, use your backup method: Use an authenticator app instead or Use a backup code.
  6. If your number has changed, you cannot self-serve. Contact support to update it — this requires an identity check.

Good to know

  • Codes are single-use and typically expire after a few minutes. Always use the newest code you received.
  • Roaming, prepaid SIMs and virtual/VoIP numbers deliver SMS unreliably. An authenticator app is more robust and works offline.
  • Repeated failed attempts can lock the login flow for a short cooling-off period. Wait it out rather than retrying.

Betabase will never ask for your password, 2FA code, seed phrase or private keys. If anyone calls or messages asking you to read out a code, it is a scam — end the conversation.
