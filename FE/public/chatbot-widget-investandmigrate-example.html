InvestAndMigrate Chatbot Widget

Embed this on investandmigrate.com. The bot uses its own OpenAI Assistant — all instructions come from your Assistant configuration in OpenAI.

WordPress / site embed snippet

Add before the closing </body> tag:

<script> window.ChatbotConfig = { apiUrl: 'https://api.betabase.pro/api/v1', adminEmail: 'info@investandmigrate.com', botAvatar: 'https://www.betabase.pro/img/bot.jpg', assistantKey: 'investandmigrate' }; </script> <script src="https://www.betabase.pro/chatbot-widget-investandmigrate.js"></script>

Configuration options

  • apiUrl — Betabase API base URL
  • adminEmail — Receives chat transcripts (default: info@investandmigrate.com)
  • botAvatar — Bot avatar image URL
  • assistantKey — Must be investandmigrate (routes to the dedicated OpenAI key + assistant on the server)

Server setup (Betabase VPS)

Add these to BE/config/config.env and restart the backend:

OPENAI_API_KEY_INVESTANDMIGRATE=sk-... OPENAI_ASSISTANT_ID_INVESTANDMIGRATE=asst_...

Create the Assistant in OpenAI with your InvestAndMigrate instructions, knowledge, and tone. The widget reads everything from that Assistant automatically.
