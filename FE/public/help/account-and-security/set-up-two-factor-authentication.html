How to set up two-factor authentication (2FA)

Set up 2FA in Settings → Security → Two-factor authentication: scan a QR code with an authenticator app, confirm a code, and save your backup codes.

Before you start

  • Install an authenticator app on your phone (any TOTP-compatible app works).
  • Have somewhere safe and offline to write down your backup codes.

Steps

  1. Open Profile → Settings → Security.
  2. Select Two-factor authentication → Set up.
  3. Choose Authenticator app (recommended) or SMS.
  4. Scan the QR code with your authenticator app. If you cannot scan, copy the setup key manually.
  5. Enter the 6-digit code the app shows to confirm the pairing.
  6. Save your backup codes. Write them down on paper or store them in a password manager — not as a screenshot in your phone gallery.
  7. Select Activate. 2FA is now required at login and for sensitive actions.

Good to know

  • 2FA is required for withdrawals, password changes, email changes and adding payout addresses.
  • Codes rotate every 30 seconds. If codes are rejected, check that your phone's clock is set to automatic time.
  • You can pair the same account with more than one device — a spare phone or tablet is a cheap insurance policy.

Betabase will never ask for your password, 2FA code, seed phrase or private keys. Anyone asking you to "read out your code to verify your account" is stealing your account.
