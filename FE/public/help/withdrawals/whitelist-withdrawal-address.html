How to add and whitelist a withdrawal address

Whitelisting restricts withdrawals to a list of addresses you have approved in advance — it is the single most effective protection against an attacker draining your account.

Steps

  1. Go to Settings → Security → Withdrawal address whitelist (or Address book).
  2. Turn on Whitelist only. With this on, crypto can be withdrawn only to addresses on the list.
  3. Select Add address.
  4. Paste the address, choose the correct network, add a memo/tag if required, and give it a recognisable label.
  5. Confirm with 2FA and click the confirmation link we email you.
  6. The address enters a cooling-off period — typically 24–72 hours — before it can be used. This delay is deliberate: it gives you time to react if the address was added by someone else.
  7. Once active, select it from the list at withdrawal time instead of pasting an address each time.

Good to know

  • Whitelisting protects against clipboard-hijacking malware, which silently swaps a copied address for the attacker's.
  • Removing an address is immediate; adding one is deliberately slow.
  • You get an email whenever an address is added, removed or used. If you receive one you did not trigger, change your password immediately and contact support.
  • The address book is per-network. The same wallet on two chains needs two entries.

Betabase will never ask for your password, 2FA code, seed phrase or private keys. No employee will ever ask you to whitelist an address they provide. Blockchain transactions are irreversible — once funds leave to a whitelisted address, they cannot be recalled.
